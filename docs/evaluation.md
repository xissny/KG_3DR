# 质量与评价规范

## 论文与图谱

正式清单不少于20篇，说明筛选依据。每条正式关系都检查原文、页码和审核者，并保留拒绝/修改历史。另对至少5篇论文通读复核，记录`data/quality_audit.json`中的错误与遗漏，不能只检查已有候选。

论文中“讨论某方法”“拿某方法做基线”“采用某组件”是三种不同语义；不应统一抽成采用关系。不同数据集、指标和实验设置不能直接做性能比较。

## 自动分类

无需人工标签的自动分类展示类别、支持事实、原文依据、分类覆盖情况与信息不足；不将模型自标注当作金标准计算F1，也不把模型自报置信度展示为准确率。类别名称归并和主题、方法语义推断均可能出错，可选结合原文修订。

## 高级分类实验

完整任务标签单独人工确认；未出现标签不自动视为负类。每类至少5个正例和5个负例。不满足时只报告缺口。

评测为小样本、传导式留一，并非独立大规模泛化证据。同一方法系列论文可能相关，结论应结合逐例预测，不夸大分数。

## 预测

测试组包含来源论文及其方法的全部组件边。同一规范实体合并后再遮蔽，防止别名重复泄漏。候选来自训练关系；缺失关系视为未知。

同时展示条件指标、覆盖率和端到端MRR；低覆盖率时不能只展示高条件MRR。

## 证据问答与研究综述

三类任务分别评价：问题回答关注正确性、参考要点和拒答；主题总结增加相关性、组织和跨论文综合；研究方向综述增加路线比较和建议合理性。模板 18 题，每类 6 题，必须替换占位实体、设置范围并由人工确认参考事实及参考要点。缺少范围内证据的题目应标记 `should_abstain=true`。

| 指标 | 口径 |
| --- | --- |
| accuracy | 正确回答数 / 已完成整体正确性评价的回答数 |
| citation_accuracy | 经原文核对支持对应陈述的引用数 / 已审核引用总数 |
| evidence_coverage | 有充分依据的事实性结论数 / 已审核事实性结论总数 |
| unsupported_ratio | 1 − evidence_coverage |
| key_point_coverage | 覆盖的人工参考要点数 / 已审核参考要点总数 |
| abstention_accuracy | 正确拒答数 / 已审核且预期应拒答的题目数 |

`expected_fact_ids` 是人工核对事实的参考集合；语义等价的结论不要求复制同一句话。`reference_points` 由审核者逐项确认，评价覆盖要点数；不可将检索到一条边直接算作回答正确。研究建议不计入事实性结论总数，建议中作为依据的事实仍要核验。

相关性、组织清晰度、跨论文综合、技术比较和建议合理性采用 1–5 分量表：1 严重偏题或错误，2 较多缺漏，3 基本可用但需修订，4 准确完整且有少量不足，5 准确、完整、清晰。综合质量考察是否建立跨论文联系；比较质量考察实验条件和关系语义；建议质量考察证据依据、推理和可验证性。

人工表单按题目固定打乱 A/B 顺序，不显示实验组名称；输出中的引用形式仍可能暴露组别，因此并非严格双盲实验。对照组保留同一问题、实体名称和论文范围，但不提供图谱关系、原文证据或参考答案。两个输出使用相同量表，保留原始输出及评分；无图谱对照不视为正式图谱事实。各指标仅使用对应字段已填写的记录，分母为零或未审核均为 null；同时报告已完成整体评价数量。

程序只自动校验事实与证据 ID 的存在和关联，不能证明语义正确。缺失引用、未知事实、重复结论 ID 被拒绝；章节和研究建议不能重新引入已拒绝结论。研究建议必须标记为推断，图谱空缺不能当作领域研究空白。若检索超过 300 条事实，结果只代表所选部分材料。

验收报告逐类列出正确、错误与拒答案例，并分析截断、抽取遗漏、范围限制及无依据陈述。没有真实人工记录时，不展示或声称正式生成质量达标。
