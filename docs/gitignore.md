# Git 忽略规则说明

本次按“保留源码、教学夹具、人工研究记录和实验依据；忽略本地依赖、运行状态、恢复备份与可再生产物”整理。忽略只影响 Git 对未跟踪文件的选择，不删除本地文件，也不会自动取消已有文件的跟踪。当前项目目录没有 `.git`，因此无法判断哪些文件此前已被跟踪。

## 忽略的文件夹

| 文件夹或规则 | 理由 |
| --- | --- |
| `/.conda/` | 当前项目内 Conda 环境，含平台相关解释器和依赖；由依赖清单重建。 |
| `/.venv/`、`/venv/` | 预留常用 Python 虚拟环境路径，避免后续切换安装方式时提交依赖。当前不存在。 |
| `__pycache__/`（任意层级） | Python 自动编译缓存，与解释器版本有关；覆盖源码、测试、脚本及样例中的缓存。 |
| `.pytest_cache/`（任意层级） | pytest 自动维护的运行状态，不是测试代码或测试数据。 |
| `/runtime/` | 安装与服务运行目录。其 `downloads/` 是下载包，`java/` 是 JDK，`browsers/` 是浏览器，`neo4j/` 含数据库、日志及进程状态；由安装和启动脚本管理，不适合随源码分发。 |
| `/data/pdfs/` | 用户导入的真实论文原文件，体积较大且需单独管理分发权限；保留论文清单，原文另行备份和交付。沿用原先忽略策略。 |
| `/data/parsed/` | 从正式 PDF 提取的全文，可运行阶段 02 重新生成；避免重复保存整篇论文内容。 |
| `/data/cache/` | 外部模型请求及响应缓存，频繁变化，可重新请求生成。删除本地缓存可能产生新的 API 费用，忽略不代表需要删除。 |
| `/data/jobs/` | 后台任务 ID、执行状态和返回结果，是本次部署的运行历史。 |
| `/data/failures/` | 抽取失败等诊断记录，应留在本地排障。 |
| `/data/locks/` | 并发互斥锁属于当前运行实例，不能跨机器复用。 |
| `/data/deleted/` | 删除论文前的本地恢复备份，包含被删除的原始及派生数据。 |
| `/data/renumbered/` | 重编号操作产生的本地恢复归档，不应随每次操作重复进入仓库。 |
| `/data/entity_resolution_backups/` | 实体合并前的事务备份；大量重复状态留给本地恢复，正式映射和审核记录仍保留。 |
| `/outputs/` | 导出与验收脚本生成的成果；`demo/` 复制前端及依赖，`graph/` 导出图谱，`screenshots/`（含 `slides/`）保存验收截图，根目录含报告、幻灯片和检查结果。可重新导出，正式提交课程成果时可单独打包。 |

`runtime/`、备份目录和 `outputs/` 下的所有更深层目录一并忽略，理由继承所属目录。

## 没有整体忽略的文件夹

| 文件夹 | 保留理由及局部例外 |
| --- | --- |
| `backend/` | API 和后台任务实现，是项目源码；仅忽略 Python 缓存。 |
| `src/` | 业务源码，包含 `classification/`、`common/`、`extraction/`、`generation/`、`graph/`、`papers/`、`prediction/`、`review/`；各模块均需要版本控制，仅忽略 Python 缓存。 |
| `frontend/` | 页面、样式和交互代码，是网页源码。 |
| `frontend/vendor/` | 页面和离线导出使用的 Cytoscape 与中文字体；尽管安装脚本可下载，保留它们能固定当前资源版本并支持离线使用。这里没有 Node 构建目录，不能套用整目录依赖忽略。 |
| `docs/` | 使用、阅读、评价及规则说明，是维护资料。 |
| `scripts/` | 分阶段命令行入口，支撑复现流程；仅忽略 Python 缓存。 |
| `setup/` | 安装、启停和浏览器验收脚本；与生成的 `runtime/` 不同，这些是重建环境的依据。仅忽略 Python 缓存。 |
| `tests/` | Python 和前端测试代码；仅忽略 Python 缓存。 |
| `neo4j/` | 手写 Cypher 查询和图样式；实际数据库位于已忽略的 `runtime/neo4j/`，不能按名称把两者一起忽略。 |
| `examples/` | 虚构教学数据、生成脚本、预存响应和教学快照，是无 API 学习及测试的基础；仅忽略 Python 缓存。 |
| `examples/responses/` | 确定的教学模拟响应，可重复验证抽取流程，无需付费模型。 |
| `examples/workspace/` | 隔离的教学工作区，虽能由脚本生成，但多个测试和浏览器验收脚本直接复制其中数据，保留可立即运行的夹具。 |
| `examples/workspace/data/` | 保留其 `pdfs/`、`parsed/`、`candidates/`、`manifests/` 及清单、标签、图谱；均属小型虚构样例。根目录正式数据忽略规则以 `/data/` 开头，不会匹配这里。 |
| `examples/workspace/experiments/` | 教学分类、预测结果和教学模型，构成配套示例。正式模型规则限定 `/experiments/*.joblib`，不影响这里。 |
| `data/` | 不整目录忽略：论文清单、筛选依据、编号注册表、别名、合并审核、质量复核及图谱快照是需要追溯的研究记录，不能一概当缓存。具体子目录按上表处理。 |
| `data/candidates/` | 不仅含模型候选，还保存人工通过、拒绝、修改及审核历史；重新调用模型不能恢复人工劳动。 |
| `data/manifests/` | 阶段输入版本摘要和产物记录，是追溯实验数据版本的依据。 |
| `experiments/` | JSON 结果可能包含模型输出、用户分类修订、评测题库和人工评价；重新运行不能等价恢复，故保留。仅忽略根层级 `.joblib` 模型二进制及残留 `.tmp`。 |
| `experiments/answers/` | 保留逐次问答及证据上下文，支撑生成质量复核；模型重跑不保证一致。 |
| `experiments/classification_taxonomy_history/` | 类别体系不可变历史快照及恢复依据，是产品功能数据，不能当作普通缓存忽略。 |

## 文件级规则

- 忽略 `.env` 与 `.env.*`，防止本地密码和 API 密钥进入版本库；明确保留 `.env.example` 配置模板。
- 忽略 `*.py[cod]`，覆盖 Python 编译字节码。
- 忽略正式 `data/`、`experiments/` 中的 `*.tmp`，对应原子写入中断的残留文件。
- 保留 `README.md`、`environment.yml`、`requirements.txt`、`requirements-lock.txt`、`data/papers_template.csv` 等说明和重建依据。
- 没有全局忽略 `*.json`、`*.pdf`、`*.csv` 或 `*.joblib`，避免隐藏教学 PDF、研究记录或教学模型。

忽略的原始论文、API 缓存、数据库和恢复备份仍需按实际需要单独备份；Git 仓库本身不会包含完整运行现场。保留的 JSON 和前端资源只是允许进入版本控制，发布前仍应按实际内容检查。
